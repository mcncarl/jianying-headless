## 草稿验收

使用仓库 `tools/smoke_test.py` 生成的两秒合成彩条视频及测试文字，执行
`build`、`verify-build`、`publish`。剪映首页出现独立测试草稿；原生界面打开后，
能看到两条视频轨、一条文字轨、画中画、变速片段及文字。播放至两秒末尾，
保存并完全退出剪映，然后从首页冷重开，同一草稿的三轨和两秒时长仍在，
再次完整播放。

退出后执行 `verify`，结果为 `verified`：原生时间线 schema `185.0.0`，
视频轨分别为 2 段和 1 段，文字轨 1 段，四份草稿镜像一致，构建源文件未变。
此轮没有执行原生 MP4 导出。测试素材和草稿均未提交。

提交前检查：`python3 tools/build_native_codec.py --rebuild-check` 再次匹配固定
指纹；`python3 -m unittest discover -s tests -q` 共 148 项通过；
`python3 tools/check_package.py` 通过，公开源码清单无官方二进制。

macOS 在首页索引临时文件创建时自动增加了 11 字节 `com.apple.provenance`。
仅在此精确配置、系统版本、索引临时文件路径，且属性在复制前已存在并保持不变时，
允许这一项系统新增属性；其余属性变化仍拒绝。首次登记在该检查处停止、未替换索引；
收窄检查后使用新的审计目录成功登记。

其他 macOS 15 版本、其他 11.4.0 build 或其他剪辑功能上完成验收。
App Store metadata 证明本机安装来源，不证明旧 build 可以从商店重新取得。

## 2026-10-02：公开真实多轨案例补验

根据维护者同意的替代口径，使用 CC BY 3.0《Big Buck Bunny》真实影片切片、抽帧与原声
建立独立测试草稿。公开 [计划、许可与复现步骤](PUBLIC-BBB-MULTITRACK.md)，以及
[脱敏机器可读记录](evidence/public-bbb-b481-acceptance.json)。

此轮贡献者仍在同一精确官方安装及 macOS 15.6.1/arm64 上验收：50.233333 秒、
23 轨、154 段、39 份独立媒体文件，其中 8 视频轨/38 段、1 音频轨/7 段、
14 文字轨/109 段。完整执行 doctor → build → verify-build → publish → 原生打开、
从零完整播放、文字临时编辑并恢复、视频控件检查、保存 → 完全退出 → 冷重开、
再从零播放到 `00:00:50:07`、保存退出 → verify。

两次保存后的 verify 都为 `verified`：schema `185.0.0`，四份活动镜像相等且物理独立，
素材绑定、文字内容/样式、位置/缩放、速度、音量、源区间通过原校验，39 份源文件 hash
未变。登记前 7 条既有首页记录在保存与冷重开后逐字段相等，仅新增本次测试记录；
不公开原始首页索引，不宣称已经快照全部私人草稿文件。

声音证据包括 7 份双声道 PCM 的非零峰值/RMS、时间线音量 0.7 的回读以及播放时
音频电平响应。此轮未做主观听音质量评价，也没有完成音频面板波形/控件的 UI 复核：
自动化滚动接口返回 `noWindowsAvailable`。该限制在记录中保留，供维护端决定是否需要人工补听。

首次等分微秒时长的计划在原生保存后被现有校验器以 `Speed changed` 拒绝：剪映按帧
取整目标时长并重新计算非 1 倍速度。改为变速段目标和源区间均对齐完整帧后，两次回读
通过。没有改动或放宽运行时校验；这也不代表任意微秒计划都可原样保存。

新增 10 项入口测试直接覆盖 doctor/helper、桥接构建器的新旧配置选择、精确文件/哈希/
工具链、错误身份/环境/组件/工具链，以及 edit build/publish/resume 和 export 在副作用前
拒绝。负向测试仅使用隔离文件与替身，不加载官方程序库。全仓 158 项测试及源码包检查
通过；两次新增桥接重建均为 `reproduced-and-verified`，哈希仍为上表固定值。
