## 草稿验收

使用仓库 `tools/smoke_test.py` 生成的两秒合成彩条视频及测试文字，执行
`build`、`verify-build`、`publish`。剪映首页出现独立测试草稿；原生界面打开后，
能看到两条视频轨、一条文字轨、画中画、变速片段及文字。播放至两秒末尾，
保存并完全退出剪映，然后从首页冷重开，同一草稿的三轨和两秒时长仍在，
再次完整播放。

退出后执行 `verify`，结果为 `verified`：原生时间线 schema `185.0.0`，
视频轨分别为 2 段和 1 段，文字轨 1 段，四份草稿镜像一致，构建源文件未变。
此轮没有执行原生 MP4 导出。测试素材和草稿均未提交。

提交前检查：`python3 tools/build_native_codec.py --rebuild-check` 再次匹配固定
指纹；`python3 -m unittest discover -s tests -q` 共 148 项通过；
`python3 tools/check_package.py` 通过，公开源码清单无官方二进制。

macOS 在首页索引临时文件创建时自动增加了 11 字节 `com.apple.provenance`。
仅在此精确配置、系统版本、索引临时文件路径，且属性在复制前已存在并保持不变时，
允许这一项系统新增属性；其余属性变化仍拒绝。首次登记在该检查处停止、未替换索引；
收窄检查后使用新的审计目录成功登记。
